# Handoff：看板 UI 原型结论（总览页 + 团队下钻页）

> 对 `handoff-prototype-ui.md` 三个设计问题的回答。原型代码：`prototype/`（一次性），已提交到 throwaway 分支 `prototype/ui-layout`。
> 用户已确认（2026-09-08）。领域词汇以 `CONTEXT.md` 为准。

## 1. 总览页：团队 × 活动矩阵怎么呈现

**选定：趋势大图矩阵（每活动一张多团队趋势图）**

- 每个活动一张大图（560px+ 宽卡片，两区各一网格）：4 条团队趋势线 + 1 条全公司均值线
- **颜色跟随团队**：团队是固定实体，按 dataviz categorical 槽位 1–4 固定分配（蓝/橙/浅绿/黄，已过调色板校验器），均值线用 de-emphasis 灰。筛选变化不重排幸存系列的颜色
- 指标切换在卡片头部（pill 按钮，一/二指标），异构指标类型（渗透率/效率提升/数量/布尔）由卡片各自承载，无需在同一布局内强行归一
- 十字线悬停一图读出全部团队数值；点击某条线下钻该团队
- 布尔活动（自动化构建部署）不画图，直接列各团队 具备/不具备
- 代码：`prototype/src/overview/VariantTrend.jsx`、`prototype/src/drilldown/multiTrendOption.js`

**被否方案及原因**

- 热力图矩阵（行内归一化顺序色阶）：用户否决——色阶回答"当前快照谁深谁浅"，但管理层要看的是趋势与走向；行内归一化还丢失绝对量级。代码留存于 `prototype/src/overview/VariantAHeatmap.jsx`
- 表格 + 迷你趋势：用户否决——精确但信息层级平，趋势被压缩成 sparkline 不可读。代码留存于 `prototype/src/overview/VariantBTable.jsx`
- 活动卡片矩阵（单色条形，每活动一卡）：未被否，作为对照保留（`?variant=C`）；其"布尔活动列状态"的处理被选定的 T 变体继承

## 2. 维度切换（团队 / 时间周月 / 版本迭代）

**选定：单行全局筛选条 + 迭代维度下通用能力区降级固定**

- 一行、置于所有内容上方：统计维度（按时间 | 按版本/迭代）→ 时间粒度（月|周）或 版本选择 → 周期选择（含"全部周期"）→ 展示指标（总览页）
- 筛选作用域覆盖下方全部图表，所有数字同切片一致；维度/粒度/版本切换时周期自动重置为最新，避免残留无效周期
- **切到迭代维度的表现**：关键研发活动区 X 轴变为迭代（事实记录按迭代标签聚合）；通用研发能力区固定按月趋势（近 6 个月）+ 显式 badge 标注"无迭代维度"——通用能力无迭代维度是领域事实，UI 用固定降级 + 标注表达，而非隐藏该区
- 代码：`prototype/src/components/FilterBar.jsx`、`prototype/src/data/compute.js`（`periodsFor` / `genFallbackFilter` / `inScope`：迭代维度按迭代标签聚合，时间维度按时间字段聚合——两种聚合路径都要保留）

## 3. 团队下钻页布局（15 活动 ≈ 25+ 指标）

**选定：A+B 结合——概览卡平铺 + 活动目录锚点 + 按需展开详情**

- 顶部 KPI 行：平均渗透率（关键活动）、平均效率提升（关键活动）、AI检视率、自动化构建部署状态；每 tile = 值 + 环比 delta + 迷你趋势
- 左侧 sticky 活动目录（关键/通用两组，点击锚点平滑滚动到对应卡片）
- 主体：单列活动趋势卡（本团队 accent vs 全公司均值灰，emphasis 形式），卡头可切指标
- 每卡右上角「详细数据」按钮就地展开：迭代分片对比条形（本团队 vs 均值）+ 分子/分母事实记录表（tabular-nums）
- 代码：`prototype/src/drilldown/DrillAFlow.jsx`（结合方案）、`DrillBFocus.jsx`（导出 `IterCompare`/`FactTable` 复用）

**被否/吸收方案及原因**

- 纯分区卡片流（原变体 A，无目录无详情）：概览好但看不了详细数据——被吸收为结合方案的骨架
- 纯目录 + 主详情（原变体 B，保留对照 `?variant=B`）：单活动信息全，但无团队整体概览、需逐个点入——其详情组件被结合方案复用

## 实现口径备忘（进 /to-spec 时保留）

- 事实记录只存分子/分母原始数，所有率前端现算；效率提升 = (Σ预估 − Σ实际)/实际，实际=0 按 0.5 人天计，负值如实展示（红色 delta 色）
- 关键研发活动按迭代标签聚合出迭代视图，按时间字段（完成周）聚合出周/月视图；通用研发能力只有时间路径
- 团队颜色固定槽位分配（颜色跟随团队实体）；条形图单色（团队是名义类目，不按值着色）
- 折线 2px、条形 ≤24px 圆角数据端、hairline 网格线、tooltip 十字线全系列、文本不穿系列色——均按 dataviz 规范，正式实现沿用
- mock 数据为种子随机（seed 20260908），刷新稳定；正式版由采集器产出
