# 03 计算层：率计算与双聚合路径

Status: ready-for-human
Blocked by: 01

纯函数计算层 + 完整测试覆盖。这是全看板正确性的核心，先于所有图表票完成。

## 范围

- 指标计算（spec §2.2）：
  - 渗透率 = 分子/分母
  - 效率提升 = (Σ预估 − Σ实际)/Σ实际；实际 = 0 时分母按 0.5 人天；负值如实返回（方向由前端着色）
- 双聚合路径（spec §3、§6.2）：
  - 时间路径：按事实记录的时间字段（需求开始/完成时间）聚合出周（周一至周日，Asia/Shanghai）/月视图
  - 迭代路径：关键研发活动按迭代标签聚合；通用研发能力无迭代维度
- 全公司均值：全部团队事实记录合并计算
- 组装函数：输入（维度筛选：团队集/时间粒度或迭代集/指标），输出图表可直用的序列数据
- 原型参照：`prototype/src/data/compute.js` 的 `periodsFor` / `inScope`（移植到后端；前端不再自行实现口径）

## 验收

- 周界（跨月周、跨年周）、迭代跨周/月的聚合均有测试
- 实际=0、负值、空数据（分母=0）三个边界的确定性行为有测试
- 效率提升的样例：预估 10/实际 5 → 100%

## 依据

spec §2.2、§3；ADR-0001；`CONTEXT.md` 的渗透率/效率提升/事实记录词条。
