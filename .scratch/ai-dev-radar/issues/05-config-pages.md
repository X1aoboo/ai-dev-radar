# 05 配置页：团队、指标目录、用户

Status: ready-for-agent
Blocked by: 01, 02

spec §6.6 的三块配置管理。

## 范围

- 团队管理：增删改查；数据源映射编辑（产品版本号列表、代码仓地址列表，JSON 结构化表单而非裸文本框）
- 指标目录管理：活动/指标增删改查；字段 = 所属活动、名称、类型（渗透率/效率提升/数量/布尔/比率）、分子/分母语义、采集方式标记
- 用户与角色管理：账号增删、角色分配、maintainer 团队绑定
- 全部仅 admin 可操作（权限检查来自 02）

## 验收

- 新增一个自定义活动 + 指标后，总览/下钻数据接口能返回它（目录驱动，无需改代码——用 07/08 的接口或本票的目录查询接口验证）
- 非 admin 访问全部 403

## 依据

spec §2.3、§6.6。
