# 06 补录：API 与页面

Status: ready-for-human
Blocked by: 01, 02

spec §6.5。补录兼作补充与修正，是第一版唯一的数据入口。

## 范围

- 补录 API：POST 事实记录，粒度 = 团队 × 迭代（关键研发活动）或周期（通用研发能力）× 指标 × 分子/分母；自动写入来源标记 `manual`、录入人（当前 session 用户）、录入时间
- **修正语义**：同键（团队+指标+迭代或周期）重复补录时追加新记录，查询时该键取最新一条 manual 记录；历史记录不删（留审计痕迹）
- 补录页：选团队 → 选迭代或周期 → 列出该范围指标（目录驱动生成表单）→ 填分子/分母；已有记录回显当前值
- 权限：maintainer 仅限关联团队，admin 全部

## 验收

- maintainer 只能补录自己团队的指标
- 同键二次补录后，03 计算层的输出使用新值
- 每条记录可追溯录入人与时间

## 依据

spec §5、§6.5；`CONTEXT.md` 的数据补录/事实记录词条。
