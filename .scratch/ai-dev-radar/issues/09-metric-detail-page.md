# 09 指标详情页

Status: ready-for-human
Blocked by: 07

spec §6.4。跨团队同一指标的趋势对比，最薄的一张页面票。

## 范围

- 选定一个指标（从总览卡或直接进入），展示全部团队该指标的趋势对比 + 全公司均值线
- 沿用全局筛选条与趋势卡组件（07）
- 布尔/数量型指标有对应展示形态（布尔列状态、数量用条形）

## 验收

- 任一目录内指标（含 05 新增的自定义指标）可进入详情页并正确渲染

## 依据

spec §6.4。
