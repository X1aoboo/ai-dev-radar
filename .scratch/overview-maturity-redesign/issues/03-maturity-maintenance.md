# 03 成熟度维护抽屉

Status: ready-for-human

## 范围

- 从总览按团队和月份打开维护抽屉，集中编辑两类活动。
- 支持复制上月已有值、预览、确认保存和清空当前月评估。
- 编辑说明并显示维护人、更新时间；viewer 只读。
- 保存成功刷新领域汇总、矩阵和雷达；失败保留编辑内容并提示。

## 验收

- 不自动沿用上月；复制和确认是显式动作。
- admin 可编辑所有团队，maintainer 只能编辑本团队，viewer 无编辑入口。
- 历史月份可编辑，清空后恢复未评估。

## Comments

**2026-09-15 实现完成**：总览维护抽屉支持两分类编辑、上月已有值显式复制、保存预览/确认、说明、清空和失败提示；后端校验 admin/maintainer/viewer 权限。浏览器已实际保存 2.90、复制上月并清空临时评估，开发库最终为 0 条成熟度记录。
