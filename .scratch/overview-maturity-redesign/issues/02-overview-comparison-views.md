# 02 总览领域比较和团队矩阵

Status: ready-for-human

## 范围

- 总览默认领域视角、关键研发活动、当前月。
- 领域统计卡、成熟度条形图、雷达和等级分布。
- 团队视角矩阵、三团队雷达对比、领域基线、数值差值表。
- 关键研发活动和通用研发能力切换；指标集中比较区及现有下钻入口。
- 视角、分类、月份、对比团队、基线和排序 URL 持久化。

## 验收

- 未评估不绘制成 0 或完整多边形；矩阵可横向滚动，文字和键盘可操作。
- 3 个团队限制、稳定颜色、缺轴、排序、独立指标筛选和刷新恢复有效。
