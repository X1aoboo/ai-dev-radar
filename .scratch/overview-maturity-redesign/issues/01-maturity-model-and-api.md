# 01 成熟度模型、聚合和接口

Status: ready-for-human

## 范围

- 新增月度成熟度存储和启动迁移，不生成历史数据。
- 新增精确十进制校验、等级映射、领域平均、覆盖率和等级分布纯计算模块。
- 新增成熟度查询、原始记录查询、按团队月份保存和清空接口。
- 后端校验团队、活动、月份、唯一性和 admin/maintainer/viewer 权限。

## 验收

- 0/0.99/1/2.90/4.10/5 和整数边界计算正确；越界、超过两位小数、未知团队/活动拒绝。
- 缺失、真实 0、部分评估和整月无数据语义可区分。
- 聚合分级不受展示四舍五入影响；保存失败不产生半条记录。
- 现有 `/api/compute` 和旧数据接口测试继续通过。
