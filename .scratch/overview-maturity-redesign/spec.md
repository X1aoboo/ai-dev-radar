# 研发总览成熟度重构规格

## 目标

总览先比较领域整体和团队短板，再下钻到关键研发活动与通用研发能力的指标。领域固定为全部团队；默认展示关键研发活动和当前评估月。成熟度按月维护，并与指标的周/月、版本/迭代筛选独立展示。

## 领域视角

- 顶部展示团队数、当月评估覆盖率、相对优势和相对薄弱能力点；并列保留，不强制唯一。
- 横向成熟度条形图与领域雷达并列。条形图默认活动目录顺序，也支持按领域平均分排序；雷达轴顺序固定。
- 每个活动显示领域平均分、等级、已评估团队数和等级分布。
- 下方指标以集中比较区呈现，默认不展开全部趋势卡。

## 团队视角

- 以团队×活动/能力点矩阵为主，格子同时显示等级和两位小数分值；未评估显示灰色“—”，不等于 0。
- 点击团队加入雷达对比，最多 3 个，默认不选。领域基线为灰色虚线且可关闭。
- 数值表展示分值和相对领域平均差值，不以雷达面积排名。
- 点击能力列或矩阵单元格打开现有指标与趋势详情；有权限时可打开成熟度维护抽屉。

## 数据和口径

- 新增 `团队 × 活动 × 评估月` 唯一的成熟度记录；分值精确十进制存储，范围 0–5，最多两位小数。
- 等级为 `floor(分值)`：L0 未建设、L1 建设中、L2 试点中、L3 推广中、L4 规模使用、L5 成熟运营。
- 领域平均按已评估团队分值等权平均，再对未四舍五入的平均值取 `floor`；展示分值保留两位小数。
- 未评估不参与平均；覆盖率分母为全部团队×当前分类活动数；没有任何记录时明确显示未评估。
- 指标渗透率/应用比率、效率、数量、布尔分别展示；保留原始分子、分母和样本量。领域指标使用团队原始分子分母合并计算；现有全公司均值接口保持独立对照含义。
- 通用能力没有迭代维度，沿用现有明确标注的时间回退行为。

## 维护和权限

- 按团队和月份集中编辑两类活动。默认不自动沿用上月；可以复制上月已有值，预览确认后才创建当月记录，也可以清空当月评估。
- admin 可维护全部团队；maintainer 只能维护绑定团队；viewer 只读。权限在后端再次校验。
- 查询与保存响应返回原始分值、等级、说明、维护人和更新时间；领域聚合由后端统一计算。
- 视角、分类、评估月、对比团队、基线开关和排序写入 URL，可刷新和返回恢复。

## 非目标

- 不新增组织领域实体。
- 不实现自动评分、达标阈值或综合团队排名。
- 不以迁移生成虚构的历史评估；迁移只创建成熟度存储。
- 人工维护数据不声称已经由指标自动验证。

## 验收场景

覆盖 0/0.99/1/2.90/4.10/5、整数边界、缺失/真实 0/部分评估/整月无数据、复制上月、清空、历史月、保存失败、跨团队权限、唯一性、非法分值、不存在团队或活动、两层切换、独立筛选、3 团队限制、缺轴、排序、URL 恢复、指标原始数合并以及窄屏矩阵横向滚动和键盘操作。
