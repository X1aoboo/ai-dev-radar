# ai-dev-radar UI 原型（一次性代码）

> 原型计划：总览页与团队下钻页的布局对比，同一路由用 `?variant=` 切换，底部浮动条循环切换，←/→ 键也可。
>
> **已拍板（2026-09-08 用户反馈）**：
> - 总览页 = **趋势大图矩阵**（变体 T，默认）：每活动一张大图，4 条团队趋势线（固定色）+ 全公司均值。否掉：热力图（A）、表格+迷你趋势（B）。
> - 团队下钻页 = **A+B 结合**（变体 A，默认）：KPI 行 + 左侧活动目录锚点 + 趋势卡平铺，每卡可展开“详细数据”（迭代分片对比 + 事实表）。变体 B（纯目录+主详情）保留对照。
> - 总览变体 C（活动卡片矩阵）保留对照。

## 运行

```bash
cd prototype
npm install
npm run dev      # http://localhost:5175
```

## 要回答的设计问题

1. 总览页团队 × 活动矩阵怎么呈现（变体 A/B/C）
2. 团队/时间/版本迭代三正交维度的切换交互（顶部筛选行；切到迭代维度时通用研发能力区固定按月展示并加标注）
3. 团队下钻页 15 活动 ≈ 25 指标的信息密度组织（下钻变体 A/B）

## 口径（对齐主项目 CONTEXT.md）

- 事实记录 = 团队 × 指标 × 迭代（关键研发活动）或纯时间（通用研发能力），只存分子/分母原始数
- 所有率由前端现算：渗透率 = AI 使用数/总数；效率提升 = (Σ预估人天 − Σ实际人天)/实际人天，实际=0 时分母按 0.5 人天计，负值如实展示
- mock 数据为种子随机（seed 固定，刷新不变）

## 图表规范

遵循 dataviz 技能参考实例调色板（未做品牌替换）：顺序蓝 ramp 做热力图/幅度，categorical 前 4 槽做折线（校验通过），团队条形图用单色 slot-1（团队是名义类目，不按值着色）。
