# Prototypes

评审用前端原型，不是生产代码，不连接后端、不写入数据。

约定：

- 每个前端变更一个目录：`prototypes/<change-name>/`。
- 至少包含 `index.html` 与 `README.md`；静态资源使用相对路径，可直接用浏览器打开。
- 页面必须标注示意数据、统计口径、空态和未决项。
- 原型链接、覆盖视图和评审结论写入对应 Change Design；评审通过后才能进入实现。
- 原型不替代 `DESIGN.md`、`UX-CONTRACT.md`、业务/架构设计文档或视觉验收基线。
