# Glossary

术语唯一维护入口是根目录 [CONTEXT.md](../CONTEXT.md)。本项目仍为单上下文，不复制第二套定义。

- 数据归属：团队、团队成员、产品、产品版本、开发迭代期。
- 指标体系：关键研发活动、通用研发能力、渗透率、效率提升、全公司均值。
- 独立评估：成熟度评估记录、评估月、成熟度等级。
- 数据管理：数据域、源数据记录、临时数据、数据变更日志、事实记录。

修改术语时更新 CONTEXT；业务规则和运行结构分别维护在 [Business](business/index.md) 和 [Architecture](architecture/overview.md)。
