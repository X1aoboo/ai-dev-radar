# 团队效能分析与成熟度

## 目标和边界

比较多个团队的 AI 研发效能、活动成熟度和短板，提供总览、团队下钻及指标详情。覆盖关键研发活动和通用研发能力；成熟度为人工判断，不是指标推导。当前看板仍基于 FactRecord，不能将 IR 工作台的更新描述为已自动影响看板。

## 核心场景

洞察拆为三个同级入口：`/` 研发总览面向管理者按“上下文与分析筛选 → 管理摘要 → 核心指标趋势 → Signal → 成熟度趋势 → 单指标团队排名/能力画像 → 研发生命周期 → 下钻”展示选定分析月份；`/analytics/activities` 独立展示关键研发活动；`/analytics/capabilities` 使用能力结构目录选择单项通用研发能力，并在详情区呈现当前成熟度、原始指标趋势或布尔状态。总览管理摘要展示两类成熟度和目录中真实存在的代表性事实指标，各指标保留原单位，不构造综合 AI 分。当前没有业务 Target 或外部行业基准，因此不展示目标达成或外部基准结论。团队排名只能切换到一个有真实数值事实的指标，并以同指标 `company_average`（全公司均值）作为参考；没有可用事实时显示明确不可排名状态。

页面内容区的 PageHeader 负责标题和描述。活动页“分析筛选”统一管理成熟度月份、指标选择、统计维度、时间粒度及周期；维度、粒度、版本/迭代、周期和所选指标写入 URL，事实图表使用多团队序列及同指标 `company_average`。选定周期驱动当前事实/布尔状态及趋势焦点；“全部周期”只保留完整趋势，不显示单周期快照。成熟度仍按独立选择的自然月计算，`month` 同时锚定按时间的事实窗口，活动与能力页面共用该月份。能力页原始指标的粒度控制也位于“分析筛选”工具栏中；成熟度写入迁移到数据管理下的 `/data/maturity`。Signal 摘要只展示数量和最高级别，详情在默认关闭的右侧抽屉中按优先级提供证据。Insight 卡展示成熟度领域平均或真实指标的当前值、环比、近六个月趋势以及 best/weak 项。

Signal 顺序为负提效、成熟度/事实缺失、低于全公司均值的团队-活动组合；每个有指标事实的信号可下钻到证据，相对差距只称“相对靠后”，有权限的成熟度缺失可进入维护。关键研发活动用 8 项活动对照矩阵把成熟度、AI 渗透率/活动比率、提效率、数据状态和下钻放在同一行，多率指标分行，不跨活动计算虚假平均。通用研发能力按目录实际类型展示比率、数量、布尔状态或成熟度，不渲染不存在的空提效模块。选定月份没有事实时显示明确空状态，不回退到其他月份；趋势窗口缺失保留断点，不补零。成熟度雷达和能力点明细组成能力画像；缺失轴不补零。

总览的研发生命周期按现有目录代码展示六个阶段代表项：需求 `sa-ir-pen`、设计 `se-eff`、开发 `cd-eff`、检视 `mrr-rate`、测试 `tcg-rate`、交付 `ad-bool`。每阶段保留自己的指标名、当前事实和同指标近六个月趋势；交付布尔状态不生成趋势或领域均值。各阶段不比较不同单位的数值，不累加阶段分数。

完整团队×能力点矩阵默认收起，展开后包含成熟度领域平均行；桌面固定团队列，移动端保留局部横向滚动提示。活动页支持按时间或版本/迭代筛选，时间粒度为月/周/日，周期可选全部或单周期，指标可切换为全部或单项；时间窗口分别为近六个月、近十二周、近三十天，成熟度始终按独立的自然月。通用研发能力原始指标可切换月/周/日，成熟度仍固定按自然月；布尔能力使用团队状态列表，不绘制 0/1 折线或全公司均值。团队下钻保留 KPI 行、活动目录、核心趋势和按需的详细数据；成熟度画像比较团队与领域平均，事实趋势以 `company_average`（全公司均值）作同指标参考，未评估分值保留为空。指标详情按 Result → Comparison → Evidence 展示：当前全公司均值、同指标团队比较/趋势，以及默认折叠的当前周期团队原始事实。量化详情分列 `company_average` 与 `domain_summary` 的结果、原始分子/分母；前者为团队结果算术平均，后者合并原始量后重算，不互相替代。目录类型仍决定率、数量柱图或布尔状态。团队、版本、迭代、时间粒度与时间字段影响对应事实查询；通用研发能力不支持迭代维度。

## 指标规则

- 每个逻辑键优先最新人工事实，否则取最新自动事实；同时间按 ID 决定顺序。关键活动键为团队/指标/迭代，纯时间键为团队/指标/开始与结束日期。
- 日/周/月按选定开始或结束日期归属，日期采用 Asia/Shanghai；迭代按标签归属，不按日期重新分配。日周期是自然日，空档保留为空周期。
- 渗透率/比率为合计分子除以合计分母，分母非正返回空值。数量为合计分子。效率为 `(合计预估 - 合计实际) / 合计实际`；实际非正时使用 0.5 人天，二者均为 0 时返回空值。
- `company_average` 保留各非空团队指标值的算术平均；`domain_summary` 合并团队原始数再计算，二者不能混用。
- 总览事实基线固定使用选定月份的 `company_average`；`domain_summary` 不作为总览展示口径。有效团队数从同月团队点计数，空值不补零。
- 未设置单周期的布尔能力当前状态使用最近有效 `snapshot`；明确选择单周期的布尔详情读取该周期 `series.values`。缺失保持未知、不当作 false，也不回退到其他周期；布尔指标不生成全公司均值趋势。数量柱图仅用于指标详情。

## 成熟度规则与生命周期

记录唯一粒度是团队/活动/评估月。分值 0–5，最多两位小数；保存规范化十进制字符串，使用 Decimal 计算。团队等级为 floor；领域按已评估团队等权平均后 floor，展示四舍五入不影响等级。未评估不等于 0，部分评估需要保留覆盖信息。

新月份不自动继承。维护者可显式预览并复制上月，确认后保存；清空删除对应月记录，恢复未评估。admin 可维护全部团队，maintainer 仅绑定团队，viewer 只读；后端再次校验权限。
