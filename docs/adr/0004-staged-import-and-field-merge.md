# 导入和采集先进入临时态，并按字段合并

## Status
部分被 [ADR-0012](0012-ir-excel-import-upsert-and-field-registry.md) 取代：文件导入新增显式 `upsert` 模式，可选择用非空值覆盖正式值；临时批次、整批校验、错误行阻断、确认和审计规则继续有效。自动采集仍固定只补空字段。

文件导入和自动采集结果先保存为临时数据，整批校验通过后由用户确认。新源数据记录直接新增；按源数据 ID 命中的正式记录只补空字段，不覆盖已有值。页面手工编辑是显式修改，可以覆盖已有值，并写入数据变更日志；AI 属性额外保留字段级来源、维护人和维护时间。

## Consequences

- 临时数据必须能展示校验错误、警告和正式值/临时值差异。
- 批次存在任何错误时不能确认，正确行也不能部分入库。
- 未匹配的责任人工号允许入库，但要标记待匹配，后续可按工号关联团队成员。
