# 源数据优先，AI 指标由源数据计算

数据管理工作台以 IR、AR、SR、DTS、MR 等数据域的源数据记录为正式业务数据；AI 属性附着在源数据记录上，AI 度量指标按规则从有效源数据实时计算。采集器负责标准化源数据，不直接把平台结果压缩成分子分母事实记录。这样可以支持详细数据查询、编辑、导入和后续增加指标，而不需要为每个新指标重新采集一份数据。

## Consequences

- 当前看板保留适配层，旧版事实记录仍可继续提供兼容数据。
- 数据域拥有明确字段和校验规则，不能用一个通用比率表替代源数据。
- 指标定义必须明确来源数据域、筛选条件和计算规则；复杂规则可以保留在计算实现中。
