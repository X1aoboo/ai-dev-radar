# AI 研发数据网关协议 1.0.0

版本：`1.0.0`
状态：Unreleased
发布日期：—
兼容级别：初始 major 基线
Git tag：—

## Added

- 确立“AI 研发数据网关”（AI Engineering Data Gateway）及服务标识 `ai-dev-data-gateway`。
- 发布静态能力目录；`requirements.ir.collection` 为首个 available 能力，其他数据源能力为 planned。
- 发布同步 Bearer HTTPS `POST /v1/collections/ir` 请求、成功响应和标准错误协议。
- 规定产品与版本联合查询范围、带时区半开窗口、request_id 回显、严格字段和 10000 条上限；Gateway 线协议不接收 Radar 团队名称。
- 响应记录同时返回 `product_name` 与 `version_name`；`business_module` 无有效值时由 Radar 规范化为 `通用模块`。
- 规定 Gateway 与 Radar 的职责、防腐边界、安全约束和脱敏要求。
- 建立最新全量基线、逐版本变更文档、SemVer 和 Git tag 发布机制。

## Changed

- 契约事实源从 Radar Pydantic 模型及独立 JSON Schema 快照迁移为实现中立的能力说明书与 OpenAPI 基线。

## Deprecated

- `docs/contracts/collector-ir-v1.schema.json` 独立快照及其“实现生成契约”维护方式将在 1.0.0 发布时停止使用。

## Removed

- 无已发布线协议字段或端点删除；本版本建立首个 IR v1 线格式。

## Fixed

- 明确 `request_id` 只用于关联而非幂等。
- 明确 planned 能力不是可调用承诺。
- 明确各标准 HTTP 错误的 retryable 语义。

## Consumer Impact

- Radar：保留现有 IR 调用行为，将 Pydantic 模型调整为协议消费者并通过一致性测试校验。
- Gateway：按本版本基线实现产品版本对查询和 IR provider contract，不需要读取 Radar 源码，也不需要理解 Radar 团队实体。
- 迁移：尚无已发布 Gateway 实现；无需线上兼容迁移。

## Validation

- 发布前校验 OpenAPI、版本索引、能力标识、示例和 Radar consumer contract tests。
- 真实 Gateway provider contract 与内部平台联调等待 Gateway 仓库实现后验证。
